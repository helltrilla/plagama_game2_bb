# 00 — Обзор игры

## Суть
Игрок управляет ragdoll-стантменом. Цель — **получить максимум урона** (ломать кости), чтобы заработать деньги, купить апгрейды и открыть уровни. Это игра про разрушение, а не про выживание.

## Core loop
1. Выбор уровня → персонаж на стартовой платформе.
2. **Launch** (пробел/кнопка) → падение/полёт.
3. Во время полёта игрок **меняет гравитацию**, чтобы врезаться в больше препятствий, отскакивать между стенами/потолком/полом и набирать комбо.
4. Раунд заканчивается, когда ragdoll почти неподвижен N секунд или истёк таймер.
5. Итог: общий урон, сломанные кости, комбо, награда → магазин апгрейдов → следующий раунд.

## Уникальная фишка: Gravity Flip
- 6 направлений (±X, ±Y, ±Z); на мобилке достаточно 4 (вверх/вниз/влево/вправо относительно камеры).
- Cooldown смены (по умолчанию 0.6 с, апгрейдится) + индикатор направления (стрелка и цветная рамка экрана).
- **Gravity Slam:** удар в течение 0.5 с после смены гравитации даёт бонус к урону.
- Опционально (позже): зоны гравитации на уровнях, которые сами переключают направление.

## Визуальный стиль
- Яркий low-poly, «краш-тест лаборатория»: чистые цвета, мягкие тени, лёгкий туман.
- Манекен жёлто-оранжевый с чёрными маркерами; сломанные кости подсвечиваются красным.
- Цвета гравитации: down = синий, up = красный, left = зелёный, right = жёлтый (плюс форма иконки для дальтоников).
