# 05 — Производительность и визуал

## Производительность
- Цель: 60 FPS на среднем смартфоне, минимум 30 на слабых.
- `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`; авто-понижение качества (тени, pixelRatio) по средней длительности кадра.
- 1 directional light + hemisphere; тени 1024 (мобилка 512 или off); без тяжёлого post-processing.
- Instancing/merge геометрии уровней; переиспользовать материалы; пулы частиц и floating text.
- Fixed timestep физики 1/60 (максимум 3 шага за кадр), рендер с интерполяцией.
- Без аллокаций в горячем цикле.
- Освобождать геометрии/материалы/физические тела при смене раунда (нет утечек).

## Game feel
- Hit-stop 40–60 мс на сильных ударах.
- Screen shake пропорционально силе удара.
- Всплывающие числа урона, красные вспышки на переломах.
- Звук хруста с вариациями питча; отдельные звуки смены гравитации, комбо, покупки.
- Вибрация на мобилке (опционально, отключаемая).
